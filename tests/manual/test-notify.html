Tab Monitor & Alerter — Manual Test Page

Load this page in a monitored tab to verify each alert trigger path.
Open the extension popup and enable monitoring for this tab before testing.

⚠️ Paths 2 & 3 (DOM triggers) require a localhost URL.
The extension’s DEFAULT_DOM_TRIGGERS map only activates the MutationObserver for known hostnames — file:// URLs have no hostname and will never match.

Path 1 — Notification API proxy

Fires new window.Notification(). The extension intercepts this in the MAIN world and sends TAB_ALERTER_NOTIFICATION.

Path 2 — DOM mutation: new node (childList)

Appends a <button aria-label="Approve"> — the selector in DEFAULT_DOM_TRIGGERS for localhost and perplexity.ai.

Requires localhost — see setup note above.

Path 3 — DOM mutation: attribute change

Creates a button node, then sets aria-label="Approve" on it as a separate operation. The MutationObserver watches both childList and attributes (with a tight attributeFilter), so this should be caught.
Expected: alert fires.
Requires localhost — see setup note above.

Path 4 — Title change (background SW)

Modifies document.title. The background SW listens to chrome.tabs.onUpdated for title changes.
