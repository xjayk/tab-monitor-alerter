Path 1 — Notification API proxy

Fires new window.Notification(). The extension intercepts this in the MAIN world and sends TAB_ALERTER_NOTIFICATION.

Path 2 — DOM mutation: new node (childList)

Appends a <button aria-label="Approve"> — the selector in DEFAULT_DOM_TRIGGERS for perplexity.ai.
Expected: alert fires. If it doesn’t, the handshake or selector is broken.

Path 3 — DOM mutation: attribute change (known gap ⚠️)

Creates a button then sets aria-label="Approve" on it. The MutationObserver only watches addedNodes, so this should NOT alert until attributes: true is added to the observer config.

Path 4 — Title change (background SW)

Modifies document.title. The background SW listens to chrome.tabs.onUpdated for title changes.
